Checkpoint · try the real contract (testnet)

The hamster's work is recorded on Ethereum, but the reward (SQK tokens) is only created when someone presses a button called a checkpoint. Anyone is allowed to press it, no special permission needed. This page walks you through it in 4 small steps. It only works on Sepolia, a practice network where nothing has real value.

1

Is it ready?

Checking…

Reading the contract…

2

Connect your wallet

You need a wallet such as MetaMask, set to the Sepolia test network, with a tiny bit of free Sepolia test ETH to pay the network fee (called "gas"). Connecting only shows this page your public address. It cannot move your funds.

3

Test it first (free)

This asks the contract "would this work?" without sending anything. It costs nothing and changes nothing.

4

Send it

Only when the light is green and the test passed. Your wallet will open and show the details: read them, then confirm or cancel. Please send it once per green light; repeating transactions does not give you anything extra.

Safety and details

This is a community page, not run by the Squeekchain team. It talks only to the contract 0x3beE588fC20dE788Bac17d33b41Da7346cb27EC4 (SqueekMining, Sepolia), copied from the official deployment record. Check that it matches before you sign.

The page never asks for your seed phrase or private key and never will. Your wallet does the signing. If a wallet window ever asks for something that does not match "checkpoint", cancel.

The only function used is checkpoint(), with no input. If something fails, the page shows the reason and stops. It does not retry by itself.
